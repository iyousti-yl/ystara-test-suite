# PR note template

Every pull request starts with this block so the codebase stays understandable to one maintainer.

**What this changes (plain language):** one or two sentences a non-developer could follow.

**Why:** the plan item or problem it serves.

**How it works:** the two or three moving parts, with file paths.

**How to check it:** the command to run or the thing to click.

**What it does not do yet:** so nobody assumes more than shipped.
